A chess engine in 4 KB of Python for make.fun's tiny-chess-01: 0x88 alpha-beta + quiescence + transposition table + killer moves + MVV-LVA ordering, iterative deepening to a fixed node budget, incremental tapered eval (material + piece-square tables + bishop pair). Deterministic: no clock, no randomness.

## Run it

```sh
python3 main.py
```
